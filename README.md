# Hush Hollow: support and privacy pages

The two public pages the App Store listing links to, served by GitHub Pages:

- Support: https://nickfromlater.github.io/hushhollow/
- Privacy policy: https://nickfromlater.github.io/hushhollow/privacy/

Plain HTML, no build step, no scripts, no third-party requests. The fonts in `assets/` are subsets of Bagel Fat One and
Figtree under the SIL Open Font License (`assets/FONTS-OFL.txt`). The game itself lives in a private repository.
